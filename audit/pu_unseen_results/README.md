# Unseen source: diabetes progression threshold challenge

This study uses a new public dataset with a prespecified binary high-progression threshold of 180. It is neither a clinical diagnostic threshold nor external hospital validation. Three seeds, SCAR and feature-dependent SAR, and two disjoint test partitions are evaluated. The original true outcomes are masked during all PU training and used only for untouched test scoring. The five prior-established baseline algorithms are NOT all possible competitors; the 31-method full synthetic suite remains separate.
The matched neural teacher and both test cohorts support tree-attribution and conservative rank-safety checks.
